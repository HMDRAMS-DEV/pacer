# Product marketing context

Pacer is a free, open-source macOS menu bar app for people using Claude and Codex weekly limits. It reads usage and reset times, compares usage with a spending plan, and suggests when to use more or ease off.

The user's stated goal is to let no capacity go to waste. Each provider's reset is its expiry, even when reset days differ. Plans default to those resets. If an earlier chosen finish passes with capacity left, catch-up guidance uses the remaining spending days; when none remain, leftovers become available today with an expiry countdown.

Voice: calm, direct, short, and specific. Say "usage", "limit", "capacity", "plan", and "reset". Distinguish remaining capacity from distance below the plan. Do not promise that Pacer can spend automatically or guarantee full utilization.

Primary action: download the signed and notarized macOS app. Keep the existing site layout, blue and purple provider colors, green unused-capacity guidance, and quiet menu-bar presentation.

Privacy: Pacer uses existing Claude and Codex sign-ins to request usage information. It does not send prompts, code, or replies. Do not claim that nothing leaves the Mac.
